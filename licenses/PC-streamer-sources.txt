Source code for the bundled PC streamer (pc/alvr_streamer_windows.zip)
=====================================================================

The PC streamer is the official ALVR nightly build, redistributed unchanged.
It contains FFmpeg 8.1 built under the GNU GPL version 3 (license text:
licenses/FFmpeg.txt inside that zip). As required by the GPL, the
corresponding source code is available here:

- ALVR v21.0.0-dev14 (nightly 2026.09.23)
  https://github.com/alvr-org/ALVR-nightly/releases
  https://github.com/alvr-org/ALVR

- FFmpeg n8.1
  https://github.com/FFmpeg/FFmpeg/tree/n8.1

- FFmpeg build scripts used by ALVR (ffmpeg-n8.1-latest-win64-gpl-shared-8.1)
  https://github.com/BtbN/FFmpeg-Builds

If any of these links stops working, open an Issue on this project's GitHub
repository and a copy of the source will be provided.
